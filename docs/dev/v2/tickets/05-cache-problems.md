# 05: 缓存三大问题（lab 02）

**What to build:** 在三条真实链路上分别复现穿透、击穿、雪崩，并给出修复：

| 问题 | 真实链路 | 错误版本 | 正确版本 |
|---|---|---|---|
| 穿透 | `apikey:{sha256}` 查不存在的 key | 无空值缓存，每次打 DB | 空值缓存（短 TTL）+ 布隆过滤器前置 |
| 击穿 | `sess:meta:{session_id}` 热点会话 | 无互斥重建，过期瞬间 N 个请求同时回源 | 单飞（互斥锁重建）+ 逻辑过期 |
| 雪崩 | 批量 key 同时过期 | TTL 固定值 | TTL 加随机抖动 |

布隆过滤器用 Redis `BF.RESERVE`（RedisBloom 模块）；若镜像不含模块，退化为「空值缓存 +
本地布隆」并在 README 写明取舍。

🗣 大白话：缓存不是「加了就快」，它会以三种固定姿势咬你——查不存在的、热点过期的、一起过期的。
