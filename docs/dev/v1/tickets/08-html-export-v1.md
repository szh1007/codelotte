# 08: HTML 会话导出 v1

**What to build:** `codelotte export --html <会话>` 把一次会话渲染为**单文件自包含 HTML**（样式脚本全部内联、零外链、离线可开）：时间线视图（消息与工具调用可折叠，含参数与结果摘要）+ 成本面板（每次调用 token、缓存命中率、峰谷价、累计费用，人民币元）。纪律：导出器是纯函数——只读会话文件、内容逐字来自执行记录，不可手工美化；一切特殊字符正确转义。

🗣 大白话：把一次会话"装订成可分享的网页"。面试时直接发这个文件（或链接），别人 30 秒看到完整轨迹和真实花费——而且是执行记录的直接渲染，做不了假。

## 实施记录（2026-10-16）

- **CLI 形态**：新增 `export` 子命令（首个子命令）：
  - `codelotte export --html|--md [序号] [-o 路径]`。
  - 序号沿用 `--resume` 的同一份列表空间：不带序号 = 最近会话的活动分支；带序号 = 指定分支。
  - 默认输出 `./<会话文件名>.<后缀>`。
  - 只读查询：**不需要密钥**。
  - 票面写法照抄；分叉过的会话导出的是一条**分支**，与 TUI 回放同一纪律。
- **`--md` 格式扩展（2026-10-16，用户提出：HTML 要开浏览器太麻烦）**：同一份记录多一条消费路径——`--html` 是**分享面**（自包含、可分发），`--md` 是**终端/编辑器直接读**的面（`render_session_markdown`，纯函数纪律与 HTML 版一致）。两者 argparse 互斥。Markdown 的结构安全：围栏**按内容动态加长**（内容里的 ``` 冲不出围栏，有测试）、表格单元格转义 `|`、标题折行压平；消息文本**原样输出**（助手回答本身就是 markdown，渲染出来更可读——这正是 Markdown 相对 HTML 的价值）。工具块标题走 `display.tool_title`——与 TUI 显示的是同一句话。
- **导出器是纯函数**（[export.py](../../../../src/codelotte/export.py)，`render_session_html(entries, catalog, *, session_name)`）：不碰文件系统、不掺导出时间戳、不依赖哈希序——同一份记录两次渲染逐字节一致（测试钉死）；调用方（cli）负责选文件、读记录、写输出。
- **零脚本是刻意的**：折叠用原生 `<details>`，样式全内联——"样式脚本全部内联"的验收因此变成更强的一条：**没有脚本**，就少一整类注入面；目检时浏览器控制台唯一的报错是 favicon 404（HTTP 服务的事，与文件无关）。
- **内容布局**：时间线（用户消息 / 回答 / 思考过程可折叠 / 工具调用可折叠：标题=工具名+参数预览+状态，展开=美化参数+结果摘要，超长截断**并标注**"共 N 字符"；中断/参数畸形/孤儿结果都有明确标注；标记层画 fork 点与迭代上限，未知条目类型如实标注不藏）+ 成本面板（每次调用：时间(UTC)/模型/时段/命中未命中/输出/命中率/费用，合计行 + 价目脚注）+ 页头（文件、记录数、cwd、版本、schema）+ 页脚（"逐字来自记录"声明）。
- **与 TUI 同源**：成本合计与命中率复用 `cost.Ledger`（不重算一份）；**由于该来源本来就与 TUI 状态栏同一实现，"逐项一致"是结构保证**，测试用真实运行记录再做一次抽查断言兜底。
- **目检**：Playwright 打开导出的真实样例（工具调用 + 两次模型调用），折叠/展开、成本数字（¥0.005206 / 87% / 21300·3100·420）与 CLI 账单逐项对上；`.playwright-mcp/` 与临时产物已清理/入 gitignore。
