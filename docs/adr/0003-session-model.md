# 会话与上下文模型：append-only JSONL 树 + 压缩即条目

Status: accepted (2026-10-13)

会话采用 append-only JSONL：

- 每条记录（消息 / 工具调用 / usage / 压缩 / 分支头）带 `id/parentId` 组成树。
- fork 与分支是一等操作。
- **compaction 本身是一条 entry**（summary + 保留边界），原始记录仍可查。
- 上下文从「活动分支」确定性重建；会话可导出 HTML。

理由：

- 它是 D4 压缩回归的数据地基——压缩条目可精确比对前后状态。
- 它是 D5 轨迹归因的数据地基——每条调用结构化、可归因。
- fork 让「同一任务换策略 A/B」零成本。
- DeepSeek 的自动前缀缓存要求**会话序列化确定性**（同前缀逐字节稳定）才能吃到 1/50 的缓存命中价；该树模型天然满足。

被否备选：扁平消息数组 + 独立快照（无法表达分支与压缩插桩）。schema 自有版本化（`session/v1`），不兼容 pi 格式。
