# 20: 实验 E1+E2：压缩回归 + 成本曲线

**What to build:** 两组核心实验的正式版 + 一篇复盘文。**E1（压缩回归）**：扩大任务规模，对触发策略 × 摘要模板做 A/B，产出"压缩次数 → 完成率 / 状态保留率"曲线与结论。**E2（成本曲线）**：测量两项干预的效果——缓存命中率提升（确定性序列化 + 前缀纪律）与 off-peak 调度（非紧急批量跑在低谷时段，五折）——给出干预前后成本对比数据。复盘文草稿：讲清楚"我怎么量化压缩质量、怎么把成本打下来"，结论部分双语（中英），供后续发布与面试引用。

🗣 大白话：产出作品最重要的两张结果图 + 一篇讲人话的文章——"记忆折叠"的考试曲线，和"省钱"的前后对比。这是简历 bullet 和面试叙事的直接素材。

**实现记录**：

- **E1 变量**：摘要模板 `seven`（七项）vs `compact`（目标/已完成/约束三节）；
  切点策略 `minimal`（最近 1 个 turn）vs `wide`（最近 2 个 turn）。CLI 增加
  `--strategy` / `--template`（可重复，笛卡尔积）与 `--combo 策略:模板`（精确选择），
  报表按 `策略 / 模板 × k` 分组，`run_suite`/`CaseResult`/`RunMeta` 携带组合标签。
- **E1 跑数**：`20261018T165516Z-8a01d9f`，6 任务 × k=0/1/3/5 × 3 组合 = **72 条案例**，
  1 次重复（651 任务调用 + 158 探针；主任务 ¥1.185327 + 探针 ¥0.374119）。完成率全部 100%，有效 checkpoint 保留率全部 100%（天花板）。成本：
  - k=5：minimal/seven ¥0.259310；minimal/compact **¥0.200221（−22.8%）**；
    wide/seven ¥0.300171（+15.8%）。
  - 全曲线：minimal/seven ¥0.563483；compact **¥0.417744（−25.9%）**；wide ¥0.578220（+2.6%）。
  - `wide` 在 k=5 达 6/6 有效，`minimal` 只有 5/6（005 turn 不够）；保留率都为 100%，
    所以 wide 的收益是“可达性”不是质量。总成本 +15.8% 包含它多做的压缩；按有效案例
    算约便宜 3.5%。只有 1 次重复，k=0 控制已有约 18% 成本噪声，百分比读作方向+量级。
  - **长任务补充**：`20261019T013233Z-8a01d9f`，007–009 × k=0/1/3/5 × 3 组合 = 36 条
    案例，311 次任务调用，¥2.096687。完成率仍 100%，保留率降到 83%–97%；
    `compact` 保留率 **93.3% vs 87.8%**、总成本 **−23.1%**；`wide` 86.7%、+2.2%，
    没有长任务收益。
- **E2**：新增 `eval cost`（离线）：读 run 的 `report.json` + 会话 usage，重算实际 /
  无缓存（命中按未命中价）/ 全峰价 / 两者叠加；输出命中率、逐调用序号曲线、节省金额。
  两轮真实跑数（正式 run 27 案例 / E4 codelotte 18 案例）：命中率 **89.0% / 89.4%**，
  实际 ¥0.205832 / ¥0.128218，无缓存+全峰价 ¥1.071706 / ¥0.688182，
  总节省 **80.8% / 81.4%**；命中率从第 1 次调用的 81.6% 升到 90%+。
