# 13: 专用测评 - 压缩回归 v0

**What to build:** 给"记忆折叠"这件事建一套专门的考试：挑选 3 条可确定性验收的任务，每条分别以"强制压缩 k=1/3/5 次"运行，产出一张质量衰减报表——① 任务完成率随压缩次数如何变化；② **关键状态保留率**：每次压缩后注入 checkpoint 问题集（"任务目标是什么？已完成哪些步骤？有哪些约束？"），用确定性比对 + 人工标注评分。跑数与评分规则文档化，锁 git ref 与随机种子保证可复现。

🗣 大白话：压缩会不会把 agent"压傻"？用考试回答——同一道题分别强制折叠记忆 1 次、3 次、5 次再做，看分数掉多少、关键的"我还记得要干嘛"丢多少。这张曲线目前在公开资料里几乎没有，是我们作品的实验资产。
