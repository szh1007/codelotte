# 07: 成本记账与展示

**What to build:** 每次模型调用按真实计价规则记录花费：区分"缓存命中/未命中"两种输入价，并按"峰谷时段"打折（DeepSeek 高峰 = 北京时间工作日 9–12 与 14–18 点，其余含周末为低谷，低谷再五折）。价目表数据化（配置驱动，不硬编码），节假日表可配置。展示三处：TUI 状态栏实时显示累计花费与缓存命中率；会话结束时打印分项账单；数据落会话（供导出与实验使用）。

🗣 大白话：给每个动作贴价签。尤其把"缓存命中便宜约 50 倍""低谷时段五折"这两件事变成看得见的数字——不然"省钱"只是口号。
