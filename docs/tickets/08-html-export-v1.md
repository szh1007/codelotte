# 08: HTML 会话导出 v1

**What to build:** `codelotte export --html <会话>` 把一次会话渲染为**单文件自包含 HTML**（样式脚本全部内联、零外链、离线可开）：时间线视图（消息与工具调用可折叠，含参数与结果摘要）+ 成本面板（每次调用 token、缓存命中率、峰谷价、累计美元）。纪律：导出器是纯函数——只读会话文件、内容逐字来自执行记录，不可手工美化；一切特殊字符正确转义。

🗣 大白话：把一次会话"装订成可分享的网页"。面试时直接发这个文件（或链接），别人 30 秒看到完整轨迹和真实花费——而且是执行记录的直接渲染，做不了假。

**Blocked by:** 06（会话树与分支 / fork）、07（成本记账与展示）

**Status:** ready-for-agent

- [ ] 导出文件零外链、断网可开；文件发送/拷贝到任何机器可读
- [ ] 时间线含每一次工具调用与结果摘要（可折叠）；成本面板数据完整
- [ ] 特殊字符正确转义（防 HTML/脚本注入，有测试）
- [ ] 导出器纯函数性测试：同一会话文件两次导出结果一致
- [ ] 导出的 HTML 与 TUI 中看到的内容逐项一致（抽查比对）
