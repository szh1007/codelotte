# 10: Docker 沙箱

**What to build:** 把 bash 命令的执行从宿主机搬到 Docker 容器：每会话一个长驻容器（命令用 `docker exec` 复用，避免每条命令冷启动），工作目录读写挂载，**家目录不进容器**（宿主的密钥、`.ssh`、`.env` 永远看不见）；网络默认拒绝（`--network none`），被拦请求以明确错误回传模型；容器有内存/CPU/超时限额（超时杀死进程组）；`--no-sandbox` 为显式逃生门（打印风险警告，且该回合每次执行在会话中标记 `env=local` 供审计）。容器生命周期跟随会话（启动/复用/清理）。

🗣 大白话：把 agent 请进"防爆箱"里干活——就算它被骗着执行了危险命令，损失也被关在盒子里，碰不到你的真实文件系统和密钥。

**Blocked by:** 04（write / edit / bash 工具 + 本地执行器）

**Status:** ready-for-agent

- [ ] 容器生命周期跟随会话：启动、命令复用、会话结束清理（有集成测试）
- [ ] 宿主敏感路径（家目录、.ssh、.env）在容器内不可见（测试证明）
- [ ] 网络默认拒绝；被拦请求回传明确错误信息
- [ ] 内存/CPU/超时限额生效；超时时进程组被整体杀死
- [ ] `--no-sandbox` 下执行在会话中标记 `env=local` 且启动时提示风险
- [ ] 沙箱集成测试为独立套件（本地 CI 可选执行，不阻塞冒烟）
