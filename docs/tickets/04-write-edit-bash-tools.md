# 04: write / edit / bash 工具 + 本地执行器

**What to build:** 补齐其余三个工具，让 agent 具备完整动手能力：`write` 整文件写入；`edit` 精确文本替换（要求目标唯一——找不到或出现多次时明确报错、回传模型重试）；`bash` 执行任意命令（含超时与输出截断：超长输出保留头尾并注明完整输出去向）。同时引入"执行器"抽象——命令执行有"本地/沙箱"两种实现的统一接口（本票先实现本地版，Docker 版是票据 10），工具代码不得直接调用系统 shell。

🗣 大白话：手和脚装齐——能写文件、能改文件、能跑命令，它从此真的能干活了；同时给"在哪执行"留好了插槽，下一阶段把执行搬到防爆箱里。
