## 口径与局限

- **实测值**来自会话 `usage` 记录（input/output/cache hit/miss/cost/period）。
- **无缓存反事实**：把命中 token 全部按未命中价重算；不是重新跑模型，也不是“关掉 provider 缓存”的实测。
- **全峰价反事实**：同一份 usage 全部按峰价重算；实际跑数落在低谷，所以这是 off-peak 调度前的理论成本。
- **缓存命中率**是 `hit / (hit + miss)`；按调用序号看前缀是否随对话增长。
- 只读会话里的 usage：压缩回归的 checkpoint 探针不写回会话，因此本报表不覆盖探针成本（E2 用通用测评 run）。
- 价目、峰谷窗口与倍率来自随包 `providers/models.json`；换价目后重跑即重算。
