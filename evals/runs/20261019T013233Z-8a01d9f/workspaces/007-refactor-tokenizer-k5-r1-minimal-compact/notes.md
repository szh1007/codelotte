# 改动说明

## 改了什么

重写了 `tokenizer.py` 中的 `tokenize` 函数，使其符合 `spec.md` 的契约。

原实现只有 `return text.split()`，无法把标点与单词分开。

新实现用一个预编译正则 `_SPLIT_RE = re.compile(r"[.,!?]|[^\s.,!?]+")`，
按 `.` `,` `!` `?` 单独成 token、其余非空白片段整体成 token 的方式匹配，
再对小写化后的文本调用 `findall`。

## 为什么这样实现

- **小写**：先 `text.lower()` 再匹配，保证返回的 token 全小写。
- **空白切分**：模式里用 `[^\s.,!?]+`，天然把任意空白（含连续空白、首尾空白）当分隔符，空 token 不会被产生，也就无需额外过滤。
- **标点分离**：`[.,!?]` 分支让每个标点各自成为一个 token。
- **数字完整**：`42`、`x=1` 这类串不包含分隔标点，会被 `[^\s.,!?]+` 整段吃掉，因此保持不变；`=` 等未列出的符号不作分隔符，符合 spec。

## 验证

按 `spec.md` 的示例及若干边界用例实测，全部通过：

| 输入 | 输出 |
| --- | --- |
| `"Hello, world!"` | `["hello", ",", "world", "!"]` |
| `"  A  b. "` | `["a", "b", "."]` |
| `"x=1"` | `["x=1"]` |
| `"42"` | `["42"]` |
| `"What? Yes."` | `["what", "?", "yes", "."]` |
| `""` / `"   "` | `[]` |

`tokenize` 的签名保持 `tokenize(text: str) -> list[str]`，公开函数名未变，调用方无需调整。
