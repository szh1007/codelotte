# 改动说明

重写了 `tokenizer.py` 中的 `tokenize`，使其符合 `spec.md` 的契约（`spec.md` 未改动，公共函数名 `tokenize` 保留）。

## 原实现的问题

`return text.split()` 只按空白切分：既没有转小写，也没有把 `.` `,` `!` `?` 拆成独立 token。

## 新实现

用一条正则 `[.,!?]|[^\s.,!?]+` 做 `findall`：

- 先匹配单个标点，保证 `.` `,` `!` `?` 每个都单独成为 token；
- 再匹配不含空白和上述标点的连续片段，从而按任意空白切分，并让这类标点天然成为分隔符；
- `findall` 只返回非空匹配，因此空 token 自动被丢弃；
- 先 `text.lower()` 完成小写化。

因为只有 `.` `,` `!` `?` 被视为分隔符，等号等字符保留在 token 内部，数字（如 `42`）也保持完整。

## 验证

覆盖了 spec 的三个示例（`"Hello, world!"`、`"  A  b. "`、`"x=1"`），以及空串、纯空白、连续标点 `"Wait...what?!"`、紧邻标点 `"A,B!C?"`、`"No.42"`、`"v1.2"` 等边界情况，结果均符合契约。
