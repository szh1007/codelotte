# 改动说明

## 改动内容

重写了 `tokenizer.py` 中的 `tokenize`。原实现只有 `text.split()`，仅满足契约中"按空白切分"这一条
（而且返回的是原始大小写、标点未分离）。

新的 `tokenize` 用一个正则 `[^\s.,!?]+|[.,!?]` 扫描文本：

- 第一个分支匹配"非空白且非 `.` `,` `!` `?`"的极大连续片段 —— 因此数字和形如 `x=1` 的片段都保持完整，
  只有契约列出的四个标点才会把单词拆开；
- 第二个分支把每个 `.` `,` `!` `?` 单独作为一个 token；
- 最后对每个匹配结果调用 `.lower()` 统一转小写，直接返回列表。

由于正则只匹配非空片段，空 token 自然不会出现（相当于满足"丢弃空 token"这一条）。

## 已验证

以下用例均通过：

- `"Hello, world!"` -> `["hello", ",", "world", "!"]`
- `"  A  b. "` -> `["a", "b", "."]`
- `"x=1"` -> `["x=1"]`
- `"42"` -> `["42"]`（数字不被拆开）
- `""` / `"   "` -> `[]`
- `"Tab\tand\nnewline"` -> `["tab", "and", "newline"]`（任意空白都切分）

`spec.md` 未做任何修改，公共函数名仍为 `tokenize`。
