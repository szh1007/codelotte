# 修改说明

重写了 `tokenizer.py` 中的 `tokenize` 函数，使其符合 `spec.md` 的契约：

- 输入先整体转为小写，输出全部为小写 token。
- 按任意空白分割。
- 将 `.` `,` `!` `?` 与单词分离，每个标点各自成为独立 token；其他符号（如 `=`）不分割。
- 丢弃空 token（例如标点之间的空片段、纯空白片段）。
- 数字保持完整，`"42"` 仍为 `"42"`。

实现方式：用 `re.compile(r"([.,!?])")` 的捕获组拆分每个单词片段，标点因此保留为独立 token，再过滤掉空字符串。

公共函数名仍为 `tokenize`，`spec.md` 未修改。

验证结果（与 `spec.md` 示例一致）：

- `"Hello, world!"` -> `["hello", ",", "world", "!"]`
- `"  A  b. "` -> `["a", "b", "."]`
- `"x=1"` -> `["x=1"]`
- `"42"` -> `["42"]`
