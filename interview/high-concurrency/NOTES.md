# 教学笔记

## 用户画像

- 目标岗位：AI/Agent 后端（Python），每天都有面试。
- 现有基础：Python、GIL、asyncio、FastAPI、Agent 项目（codelotte）；**Redis 和 Kafka/MQ 都没有实际用过**。
- 痛点：被问“Redis/Kafka 在高并发场景怎么用”时没有内容可说，缺少可复述的场景和取舍。
- 目标不是背名词，而是面试时能开口、能被追问。

## 教学偏好

- 中文、大白话、结论先行（BLUF）；先给面试可用的答案，再补原理。
- 每课 20–30 分钟能读完；内容密度高，允许一次性通读。
- 示例用 Python（redis-py / confluent-kafka / asyncio），不进入 Java 生态。
- 每个场景都要有“30–60 秒口述版”和“追问版”，因为面试是口述，不是笔试。
- 不编造生产经验；明确区分“我实测过 / 我本地跑过 / 我设计过 / 我理解取舍”。
- 练习要带反馈：选择题立即判分，口述题给参考答案和自评标准。

## 课程结构

- 11 课：总纲与容量 → Redis 基础 → 缓存问题 → Redis 高可用 → 锁与限流 → MQ 价值与选型 → Kafka → 秒杀 → 延迟队列/事务 → 过载保护 → AI 后端映射与模拟面试。
- 8 份 reference：术语表、Redis 速查、Kafka 速查、场景手册、容量数字、面试题库、AI 后端一页纸、MQ 代码层入门。
- 每次学习后，如果用户展示了真实理解，写 learning record；只记录“会用了”，不记录“讲过了”。
